> 예시 답입니다. 스펙은 [SPEC_LOGS.md](SPEC_LOGS.md)입니다. 사람이 "승인"하기 전에는 코드를 쓰지 않습니다.

| 번호 | 스펙의 주장 | 증거 종류 | 확인 방법 | 상태 |
|---|---|---|---|---|
| 1 | page 기본 1, size 기본 20 | 통합 테스트 | 값 없이 요청해 page·size 확인 | 계획 |
| 2 | id 큰 것(최근)부터 정렬 | 통합 테스트 | 첫 페이지 id가 내려가는지 확인 | 계획 |
| 3 | 2쪽은 1쪽에 이어진다 | 통합 테스트 | page=2의 첫 id 확인 | 계획 |
| 4 | 마지막 쪽은 20줄보다 적을 수 있다 | 통합 테스트 | 마지막 쪽 줄 수 확인 | 계획 |
| 5 | 범위를 넘은 page는 빈 목록과 200 | 통합 테스트 | 없는 쪽과 아주 큰 쪽 요청 | 계획 |
| 6 | page·size가 1보다 작으면 422 | 통합 테스트 | 0, 음수, 글자 요청 | 계획 |
| 7 | 줄마다 정해진 칸만 있고 리뷰 글은 없다 | 통합 테스트 | 칸 이름 집합 비교 | 계획 |
| 8 | mismatch는 true/false | 단위 테스트 | 값의 타입 확인 | 계획 |
| 9 | DB는 읽기만 한다 | 통합 테스트 | 쓰기 방법(POST)이 405인지 확인 | 계획 |
| 10 | 화면에서 목록이 보인다 | 화면 캡처 | 이번 스펙에 화면 없음 | 확인 못 함 |

승인 전 상태입니다.
